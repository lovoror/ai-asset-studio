# 3D server: Pixal3D (TRELLIS.2 backbone) image-to-3D.
#
# Unlike the other roles this one is NOT a plain pip install. The CUDA extensions have to be compiled for this
# machine's GPU (sm_120 on an RTX 50-series), so the environment must already provide:
#
#   * CUDA 12.8 toolkit + nvcc
#   * torch 2.11.0+cu128 and torchvision 0.26.0
#   * flash-attn 2.8.3
#   * nvdiffrast 0.4.0, CuMesh, FlexGEMM, o-voxel  (TRELLIS.2's rendering/mesh/voxel backends)
#   * NATTEN 0.21.0 built with NATTEN_CUDA_ARCH=12.0
#
# Build that base once by following TRELLIS.2's own installation instructions, then run this file to add the
# Pixal3D side. `scripts/bootstrap.py --role pixal3d` checks these are importable and tells you what is missing.
#
#   git clone https://github.com/TencentARC/Pixal3D.git <somewhere>   # pinned commit f7cf384
#   set STUDIO_PIXAL3D_LOCAL=<somewhere>
#
# NATTEN is the long pole (it compiles cutlass); build it first, on its own:
#   set NATTEN_CUDA_ARCH=12.0
#   python -m pip install cmake==4.1.0 && python -m pip install natten==0.21.0 --no-build-isolation
